# Extra: build the whole app at home

The workshop goes from Milestone 1 to 4 with a checkpoint in the middle, so the app is not built from scratch in the room. If you want to build the whole app yourself, these are the steps that the workshop skips. Follow them **in order**, in a project that already went through Milestones 1 and 2, with a new agent session for each one.

| Step | What you get |
|---|---|
| [Extra 1](EXTRA_1_MODEL.md) | The data model and the sample data |
| [Extra 2](EXTRA_2_PANTRY.md) | The Pantry screen working: view, add and edit ingredients |
| [Extra 3](EXTRA_3_RECIPES.md) | The recipes and their detail, with what you can cook and what's missing |
| [Extra 4](EXTRA_4_SHOPPING.md) | The shopping list, built from the missing ingredients |

When you finish, you can go back to [Milestone 3](../Milestones/STEP_3.md) and [Milestone 4](../Milestones/STEP_4.md) with your own app.
